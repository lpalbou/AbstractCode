# Acknowledgments

AbstractCode is built on (and inspired by) a lot of open-source work.

## Key dependencies (non-exhaustive)

- `prompt_toolkit` for the interactive terminal UI
- `pytest` for test coverage
- `ruff` and `black` for linting and formatting
- `ddgs` as the default DuckDuckGo-backed web search dependency used by the default toolset
- React + Vite + TypeScript for the optional web UI (`web/`)

## Abstract* ecosystem

AbstractCode is part of the Abstract* stack and relies on:
- **AbstractCore**
- **AbstractRuntime**
- **AbstractAgent**
- (optional) **AbstractFlow** for local VisualFlow runs (`abstractcode[flow]`)

Thank you to all contributors and the broader open-source community.
